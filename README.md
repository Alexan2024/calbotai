# Telegram → Apple Calendar bot

Клон механики @hidolabot под Apple Calendar. Присылаешь событие в любом формате
(текст, голосовое, фото афиши, пересланное сообщение) — бот распознаёт, показывает
карточку с кнопкой подтверждения и записывает в iCloud-календарь. Умеет менять
события, ставить напоминания и отвечать на вопросы про расписание.

**Мультипользовательский**: друзья нажимают «Запросить доступ», владелец
подтверждает кнопкой, дальше каждый подключает **свой** Apple ID (пароль
приложения) и работает со **своим** календарём. Креды шифруются (Fernet).

## Как это работает

```
ввод (текст/голос/фото/форвард)
   → нормализация в текст (Whisper для голоса, vision Claude для афиш)
   → LLM извлекает намерение + структуру события
   → карточка с ✅/❌ (+ предупреждение о возможном дубле)
   → запись в Apple Calendar этого пользователя через iCloud CalDAV
```

## Что нужно

1. **Python 3.11+**
2. **Telegram-бот**: у [@BotFather](https://t.me/BotFather) → `/newbot` → токен.
   Свой user id — у [@userinfobot](https://t.me/userinfobot) → в `ADMIN_USER_ID`.
3. **API-ключ Claude**: console.anthropic.com — используется для разбора текста
   и афиш. Модель задаётся в `LLM_MODEL` (по умолчанию `claude-sonnet-5`).
4. **Распознавание речи для голосовых** (у Claude нет STT):
   - `STT_PROVIDER=openai` + `OPENAI_API_KEY`, или
   - `STT_PROVIDER=groq` + `GROQ_API_KEY`, или
   - `STT_PROVIDER=none` — голосовые отключены.
5. **Ключ шифрования** (рекомендуется): `SECRET_KEY` — ключ Fernet для
   шифрования паролей приложений в SQLite. Сгенерировать:
   `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`
6. **Apple ID подключается прямо в боте** — переменные `ICLOUD_USERNAME` /
   `ICLOUD_PASSWORD` / `ICLOUD_CALENDAR_NAME` теперь опциональны: если заданы,
   при первом запуске они один раз импортируются как креды владельца
   (обратная совместимость), дальше всё живёт в SQLite.

### Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `TELEGRAM_TOKEN` | да | токен бота |
| `ADMIN_USER_ID` | да* | Telegram id владельца (*или первый id из старой `ALLOWED_USER_IDS`) |
| `ANTHROPIC_API_KEY` | да | разбор текста/афиш |
| `SECRET_KEY` | нет | Fernet-ключ шифрования паролей приложений |
| `STT_PROVIDER` / `OPENAI_API_KEY` / `GROQ_API_KEY` | нет | голосовые |
| `ICLOUD_USERNAME` / `ICLOUD_PASSWORD` / `ICLOUD_CALENDAR_NAME` | нет | одноразовый bootstrap кредов владельца |
| `TIMEZONE` | нет | пояс по умолчанию (у каждого юзера свой в ⚙️ Настройки) |
| `DEFAULT_REMINDERS`, `TELEGRAM_REMINDERS`, `DB_PATH`, `CALDAV_URL`, `LLM_MODEL`, `STT_MODEL` | нет | как раньше |

## Флоу нового пользователя

1. Друг открывает бота → `/start` → «🔑 Запросить доступ».
2. Владельцу приходит карточка с кнопками ✅ Дать доступ / ⛔ Отклонить.
3. После одобрения друг проходит визард: Apple ID → пароль приложения
   (appleid.apple.com → Вход и безопасность → Пароли приложений; сообщение
   с паролем бот сразу удаляет) → выбор календаря из списка.
4. Готово — все события пишутся в его календарь, в его часовом поясе.

## Использование

- **Текст**: «встреча с врачом завтра в 15:00», «дедлайн по отчёту в пятницу»
- **Голосовое**: наговори то же самое
- **Фото афиши / скриншот**: бот вытащит название, дату, место
- **Пересланное сообщение**: обработается как текст/фото
- **Кнопки**: 📅 Сегодня (день с навигацией и тапабельными событиями),
  🗓 Неделя, 📆 Месяц, 🔔 Напоминания, ⚙️ Настройки
- **⚙️ Настройки**: сменить календарь, часовой пояс, переподключить Apple ID,
  стереть свои данные; у владельца — панель 👥 Пользователи
  (принять/заблокировать/удалить)
- **Правки**: тапни событие в списке, либо текстом «перенеси встречу с врачом на 18:00»
- **Напоминания**: нативные VALARM Apple + опциональный пинг в чат
  (`TELEGRAM_REMINDERS`); `/cancel` отменяет текущий ввод

## Файлы

| Файл | Назначение |
|------|-----------|
| `bot.py` | точка входа, хендлеры, регистрация, визард Apple ID, настройки, админ-панель |
| `llm.py` | разбор текста/картинки в намерение + событие |
| `transcribe.py` | голос → текст (Whisper) |
| `calendar_client.py` | iCloud CalDAV per-user: класс `UserCalDAV` + кэш инстансов |
| `security.py` | шифрование паролей приложений (Fernet) |
| `store.py` | SQLite: пользователи + созданные события |
| `notifier.py` | планировщик Telegram-напоминаний |
| `models.py` | модель `Event` |
| `config.py` | конфиг из окружения |

## Ограничения и заметки

- **Пароли приложений**: у каждого пользователя свой app-specific password —
  обычный пароль Apple ID не подойдёт, двухфакторка обязательна.
- **Персистентность на Railway**: подключи Volume и укажи `DB_PATH=/data/tgcalbot.sqlite3`,
  иначе пользователи и их креды пропадут при редеплое. Неподтверждённые карточки
  (`PENDING` в памяти) при редеплое теряются — известное ограничение.
- **iCloud CalDAV** иногда капризничает с обнаружением календарей — бот
  фильтрует только календари с поддержкой VEVENT.
- **Редактирование текстом** ищет по названию в окне −30…+60 дней; кнопочные
  правки идут по UID и надёжнее.
- **Стоимость**: каждый разбор — вызов LLM (голос ещё и Whisper), теперь
  умноженный на число пользователей. Доступ выдавай осознанно.

## Деплой

Railway (worker), любой VPS или Raspberry Pi. Бот на long-polling, вебхук
и белый IP не нужны.
