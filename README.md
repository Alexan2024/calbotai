# Telegram → Apple Calendar bot

Клон механики @hidolabot под Apple Calendar. Присылаешь событие в любом формате
(текст, голосовое, фото афиши, пересланное сообщение) — бот распознаёт, показывает
карточку с кнопкой подтверждения и записывает в iCloud-календарь. Умеет менять
события, ставить напоминания и отвечать на вопросы про расписание.

## Как это работает

```
ввод (текст/голос/фото/форвард)
   → нормализация в текст (Whisper для голоса, gpt-4o vision для афиш)
   → LLM извлекает намерение + структуру события
   → карточка с ✅/❌
   → запись в Apple Calendar через iCloud CalDAV
```

## Что нужно

1. **Python 3.11+**
2. **Telegram-бот**: у [@BotFather](https://t.me/BotFather) → `/newbot` → токен.
   Свой user id — у [@userinfobot](https://t.me/userinfobot).
3. **OpenAI API-ключ**: platform.openai.com (используется Whisper + gpt-4o).
   Модель можно поменять в `.env` (`LLM_MODEL`), любую vision-совместимую.
4. **Apple ID + пароль приложения** (это ключевой момент):
   - зайди на appleid.apple.com → **Вход и безопасность** → **Пароли приложений**
   - создай пароль (вид `abcd-efgh-ijkl-mnop`) и вставь в `ICLOUD_PASSWORD`
   - обычный пароль от Apple ID **не подойдёт** — нужен именно app-specific
   - двухфакторная аутентификация должна быть включена

## Установка

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # заполни своими значениями
python bot.py
```

## Использование

- **Текст**: «встреча с врачом завтра в 15:00», «дедлайн по отчёту в пятницу»
- **Голосовое**: наговори то же самое
- **Фото афиши / скриншот**: пришли картинку — бот вытащит название, дату, место
- **Пересланное сообщение**: просто перешли — обработается как текст/фото
- **Расписание**: `/today`, `/week` или «что у меня в четверг»
- **Правки**: «перенеси встречу с врачом на 18:00», «удали тренировку в среду»
- **Напоминания**: по умолчанию за 60 и 10 минут (настраивается `DEFAULT_REMINDERS`);
  можно попросить явно — «напомни за час»

Напоминания ставятся двумя способами: нативные уведомления Apple (VALARM внутри
события) и, если включено `TELEGRAM_REMINDERS`, дополнительный пинг прямо в чат бота.

## Файлы

| Файл | Назначение |
|------|-----------|
| `bot.py` | точка входа, хендлеры Telegram, флоу подтверждения |
| `llm.py` | разбор текста/картинки в намерение + событие |
| `transcribe.py` | голос → текст (Whisper) |
| `calendar_client.py` | iCloud CalDAV: создать / изменить / удалить / выбрать |
| `store.py` | SQLite: созданные события (для правок и пинг-напоминаний) |
| `notifier.py` | опциональный планировщик Telegram-напоминаний |
| `models.py` | модель `Event` |
| `config.py` | конфиг из `.env` |

## Ограничения и заметки

- **Только для тебя.** `ALLOWED_USER_IDS` пропускает лишь указанные id. Убери
  ограничение — и любой сможет писать в твой календарь. Не убирай.
- **iCloud CalDAV** иногда капризничает с обнаружением календарей. Если не находит
  нужный — оставь `ICLOUD_CALENDAR_NAME` пустым (возьмётся первый) или впиши точное имя.
- **Редактирование** ищет событие по совпадению названия в окне −30…+60 дней.
  Для надёжности лучше называть событие так же, как при создании.
- **Часовой пояс** берётся из `TIMEZONE`. Проверь, что совпадает с твоим.
- **Стоимость**: каждый разбор — вызов OpenAI (голос ещё и Whisper). Для личного
  использования это копейки, но ключ держи в секрете.
- Провайдер LLM/распознавания вынесен в отдельные модули (`llm.py`, `transcribe.py`) —
  можно заменить OpenAI на другой, не трогая бота.

## Деплой

Для постоянной работы подойдёт любой VPS или Raspberry Pi:

```bash
# пример systemd-юнита /etc/systemd/system/tgcalbot.service
# ExecStart=/path/.venv/bin/python /path/bot.py
# WorkingDirectory=/path
# Restart=always
```

Бот работает на long-polling, вебхук и белый IP не нужны.
