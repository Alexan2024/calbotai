# Telegram → Apple / Google Calendar bot

Присылаешь событие в любом формате (текст, голосовое, фото афиши, пересланное
сообщение) — бот распознаёт, показывает карточку с подтверждением и записывает
в календарь. Умеет менять события, ставить напоминания, отвечать на вопросы про
расписание, искать свободное время и работать со всеми календарями сразу.

**Два провайдера**: Apple iCloud и Google Calendar. Оба работают по одному
протоколу — CalDAV с паролем приложения, поэтому подключение выглядит одинаково
и все функции бота доступны в обоих случаях.

**Мультипользовательский**: друзья нажимают «Запросить доступ», владелец
подтверждает кнопкой, дальше каждый выбирает провайдера и подключает **свой**
аккаунт. Креды шифруются (Fernet).

## Возможности

| | |
|---|---|
| 🔗 Два провайдера | Apple iCloud и Google Calendar, выбор в визарде подключения |
| 📝 Любой ввод | текст, голосовое (Whisper), фото афиши (vision), форвард |
| 📁 Мультикалендарность | чтение по **всем** календарям; выбор календаря записи прямо в карточке события |
| 🔁 Повторы | «йога каждый вторник в 19:00» → RRULE; дни рождения автоматически ежегодные |
| 🧠 Вопросы | «что у меня завтра?», «планы на неделю» |
| 🔍 Поиск слота | «найди час на этой неделе для встречи» → кнопки со свободными окнами, тап создаёт событие |
| 🧹 Массовые операции | «отмени всё в пятницу», «перенеси все созвоны завтра на час позже» — одно подтверждение на пачку |
| ⚠️ Конфликты | предупреждение о дубле по названию и о пересечении по времени |
| ↩️ Undo | кнопка «Отменить» на сообщении об успешном создании |
| ⏰ Напоминания | нативные VALARM + пинг в чат с кнопками «+15 мин» / «Карточка» |
| 🌅 Дайджест | план дня утром (час — `DIGEST_HOUR`), вкл/выкл в ⚙️ Настройки |
| 📊 Статистика | сводка за 7 дней по категориям (количество и часы) |
| ✏️ Правки | тапни событие в списке (по UID) или текстом «перенеси врача на 18:00» |

## Как это работает

```
ввод (текст/голос/фото/форвард)
   → нормализация в текст (Whisper для голоса, vision Claude для афиш)
   → LLM извлекает намерение (create/edit/query/find_slot/bulk/chitchat)
   → карточка с ✅/❌, выбором календаря, тоглами напоминаний
     (+ предупреждение о дубле/пересечении)
   → запись в выбранный календарь через CalDAV (iCloud или Google)
```

## Что нужно

1. **Python 3.11+**
2. **Telegram-бот**: у [@BotFather](https://t.me/BotFather) → `/newbot` → токен.
   Свой user id — у [@userinfobot](https://t.me/userinfobot) → в `ADMIN_USER_ID`.
3. **API-ключ Claude**: console.anthropic.com. Модель — `LLM_MODEL`.
4. **Распознавание речи** (у Claude нет STT): `STT_PROVIDER=openai|groq|none`.
5. **Ключ шифрования** (рекомендуется): `SECRET_KEY` — Fernet-ключ:
   `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`
6. **Аккаунт календаря подключается прямо в боте** — переменные `ICLOUD_*`
   опциональны (одноразовый bootstrap кредов владельца).

### Пароли приложений

| Провайдер | Где взять | Требование |
|---|---|---|
| 🍏 Apple | appleid.apple.com → Вход и безопасность → Пароли приложений | включена двухфакторная аутентификация |
| 🟦 Google | myaccount.google.com/apppasswords | включена двухэтапная аутентификация (иначе страница недоступна) |

Google показывает пароль с пробелами (`abcd efgh ijkl mnop`) — бот убирает их сам.

### Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `TELEGRAM_TOKEN` | да | токен бота |
| `ADMIN_USER_ID` | да* | Telegram id владельца (*или первый id из старой `ALLOWED_USER_IDS`) |
| `ANTHROPIC_API_KEY` | да | разбор текста/афиш |
| `SECRET_KEY` | нет | Fernet-ключ шифрования паролей приложений |
| `STT_PROVIDER` / `OPENAI_API_KEY` / `GROQ_API_KEY` | нет | голосовые |
| `ICLOUD_USERNAME` / `ICLOUD_PASSWORD` / `ICLOUD_CALENDAR_NAME` | нет | одноразовый bootstrap кредов владельца (только iCloud) |
| `CALDAV_URL` | нет | базовый URL iCloud, по умолчанию `https://caldav.icloud.com/` |
| `GOOGLE_CALDAV_URL` | нет | базовый URL Google, по умолчанию `https://apidata.googleusercontent.com/caldav/v2/` |
| `TIMEZONE` | нет | пояс по умолчанию (у каждого юзера свой в ⚙️ Настройки) |
| `DIGEST_HOUR` | нет | час утреннего дайджеста, по умолчанию `8` |

| `DEFAULT_REMINDERS`, `TELEGRAM_REMINDERS`, `DB_PATH`, `LLM_MODEL`, `STT_MODEL` | нет | как раньше |

## Флоу нового пользователя

1. `/start` → «🔑 Запросить доступ».
2. Владельцу приходит карточка ✅ / ⛔.
3. Визард: выбор провайдера (🍏 Apple / 🟦 Google) → email → пароль приложения
   (сообщение с паролем бот удаляет) → выбор календаря **по умолчанию**.
4. Готово. Читаются все календари; календарь записи можно менять в карточке события.

Сменить провайдера позже: ⚙️ Настройки → строка аккаунта → выбрать другого.
Смена аккаунта сбрасывает выбранный календарь по умолчанию.

| Файл | Назначение |
|------|-----------|
| `bot.py` | хендлеры, карточки, слоты, bulk, undo, настройки, визард провайдера, админ-панель |

## Ограничения и заметки

- **Персистентность на Railway**: подключи Volume и укажи
  `DB_PATH=/data/tgcalbot.sqlite3`. Неподтверждённые карточки (`PENDING` в
  памяти) при редеплое теряются — известное ограничение.
- **Миграции БД** применяются автоматически при старте (`ALTER TABLE`):
  `events.calendar`, `events.snooze_iso`, `users.digest_enabled`,
  `users.last_digest_date`, `users.provider`. Существующие пользователи
  получают `provider='icloud'` — переподключаться не нужно.
- **Колонки `icloud_username` / `icloud_password`** хранят креды обоих
  провайдеров; имена оставлены историческими, чтобы не ломать миграцию.
- **Google: read-only календари.** Праздники и подписки тоже отдают VEVENT, но
  писать в них нельзя — бот отсеивает их по `current-user-privilege-set`.
  Для iCloud эта проверка не выполняется (лишние запросы, поведение прежнее).
- **Google CalDAV** не поддерживает создание календарей (MKCALENDAR) и
  free-busy-query — боту это не нужно: календари создаются в вебе, свободные
  слоты считаются на своей стороне.
- **Старый эндпоинт Google** `https://www.google.com/calendar/dav` устарел и не
  поддерживается — используется `apidata.googleusercontent.com/caldav/v2/`.
- **Чтение по всем календарям** = N CalDAV-запросов на выборку. Если календарей
  много, списки чуть медленнее — это осознанный размен.
- **Повторяющиеся события**: правки и удаление применяются ко всей серии
  (отдельные вхождения пока не редактируются).
- **Bulk-операции** ограничены 30 событиями за раз.
- **Стоимость**: каждый разбор — вызов LLM (голос ещё и Whisper).

## Деплой

Railway (worker), любой VPS или Raspberry Pi. Long-polling, вебхук не нужен.
Обновление с прошлой версии: заменить файлы и перезапустить — миграция колонки
`users.provider` применится сама.
